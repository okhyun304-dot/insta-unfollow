FAQ

자주 묻는 질문

계정이 차단되지 않나요?

딜레이를 5~10초로 설정하고 하루 100~200명씩 나눠서 진행하면 대부분 문제 없습니다. PDF 가이드에 안전 사용법을 자세히 안내합니다.

Mac, Windows 둘 다 되나요?

크롬이 설치된 환경이라면 Mac, Windows 모두 동일하게 작동합니다.

한 번 사면 계속 쓸 수 있나요?

네, 1회 구매 후 영구 사용 가능합니다. 인스타그램 업데이트로 오류가 생기면 수정 파일을 무료로 드립니다.

설치가 어렵지 않나요?

스크린샷이 포함된 PDF 설명서를 함께 드립니다. 어려우신 경우 카카오톡 1:1 설치 지원까지 해드립니다.

여러 계정에 사용할 수 있나요?

1건 구매는 1계정 기준입니다. 복수 계정이 필요하신 경우 문의해 주세요.
